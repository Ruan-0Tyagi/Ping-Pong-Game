# 🏓 Ping Pong Game (Python Turtle)

A classic **2-player Ping Pong game** built using Python's **Turtle Graphics** library as part of **Day 22** of Angela Yu's *100 Days of Python Bootcamp*.

---

## 🎮 Game Preview

This is a desktop Pong game where two players control paddles and compete to score points by making the opponent miss the ball.

---

## ✨ Features

- 🏓 Two-player gameplay.
- 🎯 Ball bounces off walls and paddles.
- ⚡ Ball speed increases after every paddle hit.
- 📊 Live scoreboard.
- 🏆 Winner announcement after reaching the winning score.

---

## 🎮 Controls

| Player | Keys |
|--------|------|
| Left Paddle | **W** (Up), **S** (Down) |
| Right Paddle | **↑ Up Arrow** (Up), **↓ Down Arrow** (Down) |

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/day-22-ping-pong-game.git
```

2. Open the project folder.

```bash
cd day-22-ping-pong-game
```

3. Run the game.

```bash
python main.py
```
